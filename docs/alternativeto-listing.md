## Description
Corvus Arcade is a free, native macOS launcher for running Windows games on Apple Silicon Macs. It bundles its own engine, Wine 11 with DXMT and Apple's D3DMetal, so there is no CrossOver subscription, no Homebrew and no Terminal commands: you install the app and press Launch.

Each game runs in its own isolated Windows container. A curated one-click setup installs Battle.net and Overwatch, and you can add any other Windows game from its installer, after which Corvus Arcade reads the shortcuts the installer registered and finds the game's program for you.

The game page shows a live GPU, memory and swap readout while you play, flags problems such as tight memory with a one-tap fix, and lets you set the display mode, resolution, graphics quality and frame-rate cap per game. It speaks 33 languages and updates itself.

Corvus Arcade is early alpha. It has been tested with Battle.net plus Overwatch and with DRM-free GOG installers; anti-cheat games and DirectX 12-only titles often will not run.
