Corvus Arcade

在 Apple Silicon Mac 上運行 Windows 遊戲，使用內建引擎的原生啟動器，整合 Wine 11、DXMT 與 Apple 的 D3DMetal，無需 CrossOver 或終端機，選取遊戲後按下播放即可。

免費下載 Free · macOS 26+ · Apple Silicon only 已使用 Apple Developer ID 簽署，並經 Apple 驗證。

目前可執行的遊戲

Battle.net、Overwatch、DRM 非対応の GOG インストーラー、および単なるアーカイブ形式で配信されるゲームはすべてテスト済みで動作します。アンチチートで保護されたゲームは起動できません。DirectX 12 専用タイトルは未確認です。Corvus Arcade はインストール前に、どのゲームが対応しているかを示します。

FAQ

常見問題

《守望先鋒》是否支援 Mac？

是，適用於 Apple Silicon。Corvus Arcade 會將 Battle.net 和 Overwatch 安裝到隔離的 Windows 容器中，並透過內嵌的 Wine 11 引擎搭配 Apple 的 D3DMetal 來執行它們，因此無需 Windows 授權、Boot Camp 或虛擬機。

可以在 Apple Silicon 上運行 Windows 遊戲而不使用 CrossOver 嗎？

是。Wine 11、DXMT 和 D3DMetal 引擎已內建於應用程式中，因此無需 CrossOver 訂閱、Homebrew 或終端機指令。下載應用程式並按下「啟動」。

Corvus Arcade 是否免費？

是，它是免費的，無需帳戶，沒有遥測或追蹤，完全在您的 Mac 上運行。

可以新增哪些遊戲？

任何 Windows 遊戲，每個遊戲都有獨立的安裝程式或 .exe，且各自位於隔離容器中。《守望先鋒》是經過精選且經驗證的遊戲，而 GOG 安裝程式（免 DRM）也經過測試。反作弊遊戲以及僅支援 DirectX 12 的遊戲通常無法執行。

是否需要 Rosetta 2？

是，若缺少該項，Corvus Arcade 將為您安裝。首次執行系統檢查也會確認捆綁的引擎以及您是否有足夠的可用磁碟空間。

Corvus Arcade 安全安裝嗎？

是。每個版本均使用 Apple 開發者 ID 證書簽署，並經 Apple 核發，Apple 會在發布前掃描其是否存在惡意軟體。macOS 在您開啟應用程式時會驗證該簽章，因此您不會看到「未識別的開發者」警告。磁碟映像也經過封裝，因此即使離線也能進行檢查。Corvus Arcade 不會收集任何資料，也無需建立帳戶。

需要什麼 Mac？

An Apple Silicon Mac, meaning M1 or newer, running macOS 26 or later. Intel Macs are not supported. Battle.net plus Overwatch needs roughly 60 GB of free space.
