FAQ

Common questions

Does Overwatch work on a Mac?

Yes, on Apple Silicon. Corvus Arcade installs Battle.net and Overwatch into an isolated Windows container and runs them through a bundled Wine 11 engine with Apple's D3DMetal, so no Windows licence, Boot Camp or virtual machine is involved.

Can I run Windows games on Apple Silicon without CrossOver?

Yes. The Wine 11, DXMT and D3DMetal engine ships inside the app, so there is no CrossOver subscription, no Homebrew and no Terminal commands. Download the app and press Launch.

Is Corvus Arcade free?

Yes, it is free and has no account, no telemetry and no tracking. It runs entirely on your Mac.

Do I need Rosetta 2?

Yes, and Corvus Arcade installs it for you if it is missing. The first-run system check also confirms the bundled engine and that you have enough free disk space.

Is Corvus Arcade safe to install?

Yes. Every release is signed with an Apple Developer ID certificate and notarized by Apple, which scans it for malware before it is published. macOS verifies that signature when you open the app, so you will not see an unidentified developer warning. The disk image is stapled too, so the check works even offline. Corvus Arcade collects no data and requires no account.

What Mac do I need?

An Apple Silicon Mac, meaning M1 or newer, running macOS 26 or later. Intel Macs are not supported. Battle.net plus Overwatch needs roughly 60 GB of free space.
