Corvus Arcade

Apple Silicon Mac 에서 Windows 게임을 실행할 수 있는, CrossOver 나 터미널 없이 Wine 11, DXMT, Apple D3DMetal 이 내장된 네이티브 런처를 통해 게임을 선택하고 Play 를 누르면 바로 실행됩니다.

무료 다운로드 Free · macOS 26+ · Apple Silicon only Apple Developer ID 로 서명되어 Apple 에서 인증되었습니다.

오늘 실행 중인 게임

Battle.net 과 Overwatch, DRM 프리 GOG 설치 파일, 그리고 일반 아카이브로 제공되는 게임은 모두 테스트되어 작동합니다. 반치트 보호 게임은 실행되지 않으며, DirectX 12 전용 타이틀은 아직 검증되지 않았습니다. Corvus Arcade 는 설치 전에 해당 게임이 어떤 유형인지 알려줍니다.

실행 중

Apple Silicon 에서 실행 중인 게임

기능

런처, 툴킷 아님

원클릭 오버워치

정제된 설정은 깨끗한 컨테이너를 구축하고 Battle.net을 설치한 후 매치에 바로 진입합니다. 별도의 설정이 필요 없습니다.

포함된 엔진

DXMT 와 Apple D3DMetal 이 앱에 내장되어 있어, CrossOver 구독, Homebrew, 터미널 없이 Wine 11 을 사용할 수 있습니다.

라이브러리 한눈에 보기

홈 화면에는 모든 게임과 현재 상태 (준비됨, 재생 중, 설정 필요) 가 표시됩니다.

게임 중 촬영한 스크린샷

단축키는 전체 화면이 아닌 게임 창만 캡처합니다. 촬영된 내용은 게임 페이지의 뷰어에 열리며, 갤러리와 화살표 키로 조작할 수 있습니다.

게임별 그래픽

각 게임마다 독립적으로 DXMT 또는 D3DMetal, GPTK 3 또는 GPTK 4, 창 모드 및 프레임 레이트 제한을 선택할 수 있습니다.

GPU.. 실시간 GPU 및 메모리

게임 중 GPU 및 메모리 사용량을 게이지와 롤링 그래프로 시각화하여 작업 강도를 확인하세요.

저장 내용은 보호됩니다

게임 삭제 시 먼저 확인을 요청합니다. 삭제 대상이 되는 저장 파일의 수를 세고, 삭제 전에 이를 내보내려 할지 묻습니다.

준비 상태 확인

게임 페이지는 메모리 부족 문제를 표시하고, 플레이하기 전에 한 번의 터치로 해결책을 제공합니다.

프레임 캡 및 FPS 오버레이

프레임 레이트를 제한하여 발열과 팬 소음을 줄이고, MetalFX 업스케일링을 활성화하며, 필요할 때 실시간 FPS 읽기 값을 표시합니다.

  • 원클릭 오버워치 설치, 깔끔한 컨테이너, Battle.net, 실행 및 설정 불필요.
  • Windows 게임을 추가하세요. 각 게임은 독립된 컨테이너에 추가됩니다.
  • GOG 또는 기타 Windows 설치 파일에서 설치한 후 게임의 프로그램을 자동으로 찾습니다.
  • CrossOver, Homebrew, 또는 Terminal 없이 Wine 11, DXMT, 및 Apple D3DMetal 엔진이 포함된 번들 버전입니다.
  • 게임별 그래픽으로 DXMT 또는 D3DMetal, GPTK 3 또는 GPTK 4, MetalFX 업스케일링 지원.
  • 게임별 표시 모드, 해상도, 그래픽 품질, 그리고 프레임 레이트 제한.
  • 경기 중 Cmd-Tab 으로 전환할 수 있는 창 모드입니다.
  • 게임 중 실시간 GPU, 메모리 및 스왑 읽기값과 함께 롤링 그래프를 제공합니다.
  • 문제를 표시하고 한 번의 탭으로 해결하는 준비 상태 확인.
  • 16 GB Mac 의 낮은 메모리 경고로 닫아야 할 앱을 표시합니다.
  • 게임 런처가 시작되면 자동으로 메모리를 해제합니다.
  • 후에 버벅임을 쉽게 추적할 수 있는 내장 성능 로그입니다.
  • Metal FPS 및 프레임 시간 오버레이로, 필요할 때 켤 수 있습니다.
  • 설정에서 셰이더 캐시를 삭제하여 디스크 공간을 확보합니다.
  • Steam에 없는 게임의 경우 해당 프로그램에서 직접 가져온 게임 커버 아트를 사용합니다.
  • Windows 프로그램을 라이브러리에 드래그하여 게임을 추가합니다.
  • 컨테이너를 수리하여 누락된 폰트를 복원하고 게임 설정을 다시 적용합니다.
  • 각 게임의 디스크 사용량과 라이브러리의 총량을 확인하세요.
  • 재시작 없이 앱 내 스위치로 언어를 변경할 수 있는 33 개 언어
  • 게임 창을 단축키로 찍은 스크린샷을 내장 뷰어에 표시합니다.
  • 8 가지 색상 테마로, 네 개는 어두운 테마이고 네 개는 밝은 테마이며 기본값은 앱 아이콘에서 가져옵니다.
  • 게임을 게임 목록과 사이드바의 상단으로 고정하는 즐겨찾기입니다.
  • 이름으로 검색하고, 마지막으로 재생한 순서, 이름 또는 크기로 정렬합니다.
  • 저장 파일 보호: 게임을 제거하기 전에 저장 파일을 세어 보고 내보낼 수 있습니다.
  • macOS은 이제 Alt 키를 특수 문자 입력에 할당하지 않고, 게임에서 Alt 키를 사용할 수 있습니다.
  • 스토어 또는 아카이브 파일 이름이 잘못 된 게임 이름을 모두 수정합니다.
  • 게임, 환경설정 및 게임별 설정을 하나의 파일로 내보낸 후 다른 Mac 에서 복원하세요.
  • 게임 다운로드 전에 경고: 해당 게임은 두 백엔드 모두 지원하지 않는 그래픽 기능을 필요로 합니다.
  • Corvus Arcade는 실행에 앞서 여러 부분으로 구성된 설치 프로그램의 파일을 확인하고, 파일이 누락되었거나 손상된 경우 이를 알려줍니다.
  • 한 번의 클릭으로 설치할 수 있는 자동 업데이트.
  • Rosetta 2, 기본 엔진, 및 사용 가능한 디스크 공간에 대한 첫 실행 확인

FAQ

자주 묻는 질문

오버워치가 맥에서 작동합니까?

Apple Silicon 에서 예. Corvus Arcade 는 Battle.net 과 Overwatch 를 격리된 Windows 컨테이너에 설치하고 Apple 의 D3DMetal 과 함께 제공되는 Wine 11 엔진을 통해 실행하므로 Windows 라이선스, Boot Camp 또는 가상 머신이 필요하지 않습니다.

Apple Silicon Mac 에서 CrossOver 없이 Windows 게임을 실행할 수 있나요?

네. Wine 11, DXMT 및 D3DMetal 엔진이 앱에 포함되어 있으므로 CrossOver 구독, Homebrew 및 터미널 명령어는 필요하지 않습니다. 앱을 다운로드한 후 Launch 를 누르세요.

Corvus Arcade는 무료인가요?

네, 무료이며 계정, 원격 감시 및 추적 기능이 없습니다. 이 앱은 완전히 귀하의 Mac 에서 실행됩니다.

어떤 게임을 추가할 수 있나요?

윈도우 게임 중 설치 파일이나 .exe 파일이 각각 독립된 컨테이너에 포함된 모든 게임이 지원됩니다. Overwatch 는 검증된 제목이며, DRM 이 없는 GOG 설치 파일은 테스트되었습니다. 반치트 게임 및 DirectX 12 전용 게임은 실행되지 않을 수 있습니다.

Rosetta 2 가 필요한가요?

네, Corvus Arcade 가 누락된 경우 자동으로 설치합니다. 첫 실행 시 시스템 점검을 통해 번들 엔진과 충분한 여유 디스크 공간이 있는지 확인합니다.

Corvus Arcade 를 설치해도 안전한가요?

예. 모든 릴리스는 Apple Developer ID 인증서로 서명되며 Apple 에서 악성코드를 검사한 후 게시합니다. macOS 는 앱을 열 때 서명을 확인하므로 미확인 개발자 경고가 표시되지 않습니다. 디스크 이미지도 스탭링되어 오프라인에서도 확인이 가능합니다. Corvus Arcade 는 데이터를 수집하지 않으며 계정 등록이 필요하지 않습니다.

어떤 Mac이 필요한가요?

An Apple Silicon Mac, meaning M1 or newer, running macOS 26 or later. Intel Macs are not supported. Battle.net plus Overwatch needs roughly 60 GB of free space.
