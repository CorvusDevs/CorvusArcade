어떤 게임을 추가할 수 있나요?

윈도우 게임 중 설치 파일이나 .exe 파일이 각각 독립된 컨테이너에 포함된 모든 게임이 지원됩니다. Overwatch 는 검증된 제목이며, DRM 이 없는 GOG 설치 파일은 테스트되었습니다. 반치트 게임 및 DirectX 12 전용 게임은 실행되지 않을 수 있습니다.

설치 프로그램이 완료되면 Corvus Arcade 는 Windows 에 등록한 내용을 읽어서 게임 실행 프로그램을 자동으로 설정하므로 .exe 파일을 찾기 위한 번거로움이 없습니다.

윈도우에서 게임을 실행합니다.

이제 게임은 전체 화면 대신 창 모드로 시작할 수 있습니다.

다른 프로그램을 언제든지 선택할 수 있습니다

새 게임 실행 가능 옵션을 사용하면 나중에 시작 타겟을 수정할 수 있으며, Corvus Arcade 는 선택한 파일이 설치 프로그램인 경우 경고합니다.

여러 부분으로 구성된 게임을 설치하세요

Point Corvus Arcade에 번호가 매겨진 설치 프로그램 파일들이 들어 있는 폴더를 지정하면, 해당 파일들을 확인하고, 누락되거나 손상된 파일이 있는지 알려준 다음 설치 프로그램을 실행합니다.

성능

게임별 그래픽

각 게임마다 독립적으로 DXMT 또는 D3DMetal, GPTK 3 또는 GPTK 4, 창 모드 및 프레임 레이트 제한을 선택할 수 있습니다.

GPU.. 실시간 GPU 및 메모리

게임 중 GPU 및 메모리 사용량을 게이지와 롤링 그래프로 시각화하여 작업 강도를 확인하세요.

프레임 캡 및 FPS 오버레이

프레임 레이트를 제한하여 발열과 팬 소음을 줄이고, MetalFX 업스케일링을 활성화하며, 필요할 때 실시간 FPS 읽기 값을 표시합니다.

셰이더 캐시를 삭제합니다.

설정에서 새로운 버튼을 통해 Metal 셰이더 캐시가 사용하는 디스크 공간을 해제할 수 있습니다. 게임은 다음 실행 시 자동으로 다시 구축합니다.

준비 상태 확인

게임 페이지는 메모리 부족 문제를 표시하고, 플레이하기 전에 한 번의 터치로 해결책을 제공합니다.

라이브러리 내보내기

게임 목록, 설정 및 게임별 설정을 하나의 작은 파일로 저장하고 다른 Mac 에서 복원하세요.

안전

저장 내용은 보호됩니다

게임 삭제 시 먼저 확인을 요청합니다. 삭제 대상이 되는 저장 파일의 수를 세고, 삭제 전에 이를 내보내려 할지 묻습니다.

저장 데이터 보관소

Corvus Arcade는 먼저 현재 저장 데이터에서 안전 복원 지점을 생성합니다. 게임을 종료해야 합니다.

컨테이너 스냅샷

실험이나 주요 변경을 수행하기 전에 전체 Windows 컨테이너를 캡처하십시오. APFS 스냅샷은 빠르게 시작되며, 파일이 변경될 때만 추가 공간을 사용합니다.

컨테이너 수리

새로운 '수리' 옵션으로 누락된 글꼴을 복원하고 각 게임의 설정을 다시 적용하여 빈 메뉴와 텍스트 문제를 해결합니다. 설치된 모든 항목은 삭제되지 않습니다.

설치 실패 메시지에 그렇게 나와 있습니다

설치 프로그램이 중간에 중단되면, Corvus Arcade는 라이브러리에 빈 게임 항목을 남겨두지 않고 이를 보고합니다.

FAQ

자주 묻는 질문

오버워치가 맥에서 작동합니까?

Apple Silicon 에서 예. Corvus Arcade 는 Battle.net 과 Overwatch 를 격리된 Windows 컨테이너에 설치하고 Apple 의 D3DMetal 과 함께 제공되는 Wine 11 엔진을 통해 실행하므로 Windows 라이선스, Boot Camp 또는 가상 머신이 필요하지 않습니다.

Apple Silicon Mac 에서 CrossOver 없이 Windows 게임을 실행할 수 있나요?

네. Wine 11, DXMT 및 D3DMetal 엔진이 앱에 포함되어 있으므로 CrossOver 구독, Homebrew 및 터미널 명령어는 필요하지 않습니다. 앱을 다운로드한 후 Launch 를 누르세요.

Corvus Arcade는 무료인가요?

네, 무료이며 계정, 원격 감시 및 추적 기능이 없습니다. 이 앱은 완전히 귀하의 Mac 에서 실행됩니다.

Rosetta 2 가 필요한가요?

네, Corvus Arcade 가 누락된 경우 자동으로 설치합니다. 첫 실행 시 시스템 점검을 통해 번들 엔진과 충분한 여유 디스크 공간이 있는지 확인합니다.

Corvus Arcade 를 설치해도 안전한가요?

예. 모든 릴리스는 Apple Developer ID 인증서로 서명되며 Apple 에서 악성코드를 검사한 후 게시합니다. macOS 는 앱을 열 때 서명을 확인하므로 미확인 개발자 경고가 표시되지 않습니다. 디스크 이미지도 스탭링되어 오프라인에서도 확인이 가능합니다. Corvus Arcade 는 데이터를 수집하지 않으며 계정 등록이 필요하지 않습니다.

어떤 Mac이 필요한가요?

An Apple Silicon Mac, meaning M1 or newer, running macOS 26 or later. Intel Macs are not supported. Battle.net plus Overwatch needs roughly 60 GB of free space.
