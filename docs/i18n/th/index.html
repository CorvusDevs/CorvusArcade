Corvus Arcade

เล่นเกม Windows บน Mac ที่ใช้ชิป Apple Silicon ด้วยตัวจัดการเกมแบบพื้นเมืองที่รวมตัวเครื่องของตัวเอง ซึ่งใช้ Wine 11 พร้อม DXMT และ D3DMetal ของ Apple โดยไม่ต้องใช้ CrossOver หรือ Terminal แค่เลือกเกมแล้วกดเล่น

ดาวน์โหลดฟรี Free · macOS 26+ · Apple Silicon only ลงชื่อด้วย Apple Developer ID และผ่านการรับรองจาก Apple

อะไรใช้งานได้ตอนนี้

Battle.net, Overwatch, ตัวติดตั้ง GOG ที่ไม่มี DRM และเกมที่ส่งมาเป็นไฟล์อัดรวมล้วนผ่านการทดสอบและใช้งานได้ เกมที่มีระบบป้องกันการโกงจะไม่ทำงาน และเกมที่ใช้ DirectX 12 เท่านั้นยังไม่มีข้อมูลยืนยัน Corvus Arcade จะบอกคุณว่าเกมไหนเป็นเกมไหนก่อนการติดตั้ง

กำลังดำเนินการ

เกมบน Apple Silicon

คุณสมบัติ

ตัวเริ่มต้น ไม่ใช่ชุดเครื่องมือ

Overwatch เพียงคลิกเดียว

การตั้งค่าที่คัดสรรมาสร้างคอนเทนเนอร์ที่สะอาด ติดตั้ง Battle.net และเริ่มเล่นทันทีโดยไม่ต้องตั้งค่า

เครื่องยนต์ของคุณ รวม

Wine 11 พร้อม DXMT และ D3DMetal ของ Apple ถูกติดตั้งภายในแอปโดยไม่ต้องสมัคร CrossOver ไม่ต้องใช้ Homebrew หรือ Terminal

ภาพรวมคลังเกมของคุณ

มุมมองหน้าหลักแสดงเกมทั้งหมดพร้อมสถานะปัจจุบัน: พร้อมใช้งาน กำลังเล่น หรือต้องการการตั้งค่า

ภาพหน้าจอขณะเล่น

ลัดนี้จะบันทึกหน้าต่างเกมแทนทั้งหน้าจอ ภาพจะเปิดในผู้ชมบนหน้าของเกมนั้น พร้อมแกลเลอรี่และปุ่มลูกศร

กราฟิกต่อเกม

เลือก DXMT หรือ D3DMetal, GPTK 3 หรือ GPTK 4, โหมดหน้าต่าง และขีดจำกัดอัตราเฟรมสำหรับแต่ละเกมแยกกัน

GPU..: GPU และหน่วยความจำแบบสด

เกจและกราฟแบบเลื่อนแสดงระดับการทำงานของ GPU และหน่วยความจำขณะเล่นเกมของคุณ

การบันทึกของคุณได้รับการป้องกัน

การลบเกมจะขอความยินยอมก่อน โดยจะนับจำนวนไฟล์บันทึกที่เกี่ยวข้องและเสนอให้ส่งออกไฟล์เหล่านั้นก่อนทำการลบ

การตรวจสอบความพร้อม

หน้าเกมจะแจ้งปัญหาเช่นหน่วยความจำจำกัด และเสนอวิธีแก้ไขด้วยการแตะครั้งเดียวก่อนที่คุณจะเริ่มเล่น

การจำกัดเฟรมและซ้อนข้อมูลเฟรมต่อวินาที

จำกัดอัตราเฟรมเพื่อลดความร้อนและเสียงพัดลม เปิดใช้งาน MetalFX เพื่อปรับขนาดภาพ และแสดงอัตราการเฟรมแบบเรียลไทม์เมื่อต้องการ

รวมทุกอย่าง

รายการฟีเจอร์ทั้งหมด

  • การติดตั้ง Overwatch แบบคลิกเดียว พร้อมคอนเทนเนอร์ที่สะอาด Battle.net และการเริ่มต้น โดยไม่ต้องตั้งค่าอะไรเลย
  • เพิ่มเกม Windows ลงได้แต่ละเกมในภาชนะแยกกัน
  • ติดตั้งจากตัวติดตั้งของ GOG หรือตัวติดตั้งของ Windows แล้วค้นหาโปรแกรมของเกมให้เอง
  • มี Wine 11, DXMT และ Apple D3DMetal engine รวมอยู่ในแอปนี้ โดยไม่ต้องใช้ CrossOver, Homebrew หรือ Terminal
  • กราฟิกแบบแยกเกม รองรับ DXMT หรือ D3DMetal, GPTK 3 หรือ GPTK 4 และ MetalFX upscaling
  • โหมดแสดงผลต่อเกม ความละเอียด คุณภาพกราฟิก และขีดจำกัดเฟรมเรท
  • โหมดหน้าต่างที่ให้คุณกด Cmd-Tab ออกได้ระหว่างการแข่งขัน
  • การอ่านค่า GPU, หน่วยความจำ และพื้นที่สลับแบบเรียลไทม์พร้อมกราฟแบบหมุนขณะเล่น
  • การตรวจสอบความพร้อมที่จะระบุปัญหาและแก้ไขได้ด้วยการแตะครั้งเดียว
  • คำเตือนหน่วยความจำต่ำที่แสดงว่าแอปใดควรปิดบน Mac ขนาด 16 GB
  • ปล่อยหน่วยความจำโดยอัตโนมัติโดยการปิดตัวเริ่มต้นของเกมหลังจากเริ่มเล่นแล้ว
  • บันทึกประสิทธิภาพในตัวที่ช่วยให้ติดตามอาการกระตุกได้ง่ายขึ้นในอนาคต
  • Metal FPS และกราฟฟิกรอบเวลาเฟรมที่คุณสามารถเปิดได้เมื่อต้องการ
  • ล้างแคชเชเดอร์จาก การตั้งค่า เพื่อคืนพื้นที่ดิสก์
  • ภาพปกของทุกเกม โดยดึงมาจากโปรแกรมเกมเองเมื่อเกมไม่ได้อยู่ใน Steam
  • ลากโปรแกรม Windows มาวางบนคลังเพื่อเพิ่มเกม
  • ซ่อมแซมคอนเทนเนอร์เพื่อคืนฟอนต์ที่หายไปและตั้งค่าเกมใหม่
  • ดูพื้นที่ดิสก์ที่แต่ละเกมใช้ และพื้นที่รวมในคลังเกมของคุณ
  • รองรับ 33 ภาษาพร้อมสลับภาษาในแอปโดยไม่ต้องรีสตาร์ท
  • ภาพหน้าจอของหน้าต่างเกม ที่บันทึกด้วยลัดคีย์และแสดงในเครื่องดูไฟล์ในตัว
  • แปดธีมสี: สี่แบบมืดและสี่แบบสว่าง โดยค่าเริ่มต้นจะดึงจากไอคอนแอป
  • รายการโปรดที่ตรึงเกมไว้ด้านบนของรายการเกมและแถบด้านข้าง
  • ค้นหาตามชื่อ และจัดเรียงตามครั้งล่าสุดที่เล่น ชื่อ หรือขนาด
  • การป้องกันการสูญเสียข้อมูล: ก่อนที่จะลบเกม ไฟล์บันทึกจะถูกนับและสามารถส่งออกได้
  • ตอนนี้ Alt สามารถเข้าถึงเกมของคุณได้แล้ว macOS เดิมจะเก็บไว้สำหรับพิมพ์อักขระพิเศษ
  • เปลี่ยนชื่อเกมใดก็ได้ที่ชื่อในร้านค้าหรือชื่อไฟล์ในคลังเก็บข้อมูลผิดพลาด
  • ส่งออกเกม, การตั้งค่า และการตั้งค่าแต่ละเกมของคุณเป็นไฟล์เดียว แล้วกู้คืนบน Mac เครื่องอื่น
  • คำเตือนก่อนดาวน์โหลดเกมที่ต้องใช้ฟีเจอร์กราฟิกซึ่งไม่มีแบ็กเอนด์ใดรองรับ
  • Corvus Arcade จะตรวจสอบไฟล์ของโปรแกรมติดตั้งที่มีหลายส่วนก่อนที่จะเริ่มทำงาน และแจ้งให้ทราบหากมีไฟล์ใดขาดหายไปหรือเสียหาย
  • การอัปเดตอัตโนมัติที่คุณสามารถติดตั้งได้ด้วยการคลิกครั้งเดียว
  • การตรวจสอบครั้งแรกของ Rosetta 2 เครื่องยนต์ที่รวมมา และพื้นที่ว่างบนดิสก์

0.8.0
  • เปิดใช้งานด่วนค้นหาเกมและกิจกรรม
  • ห้องเก็บข้อมูลบันทึกเกมCorvus Arcade จะสร้างจุดคืนค่าความปลอดภัยจากข้อมูลที่บันทึกไว้ล่าสุดก่อนเป็นอันดับแรก เกมต้องถูกปิดก่อน
  • ภาพถ่ายของคอนเทนเนอร์สร้างสำเนาของคอนเทนเนอร์ Windows ทั้งหมดก่อนดำเนินการทดลองหรือเปลี่ยนแปลงสำคัญ APFS สแนปช็อตเริ่มต้นได้อย่างรวดเร็วและใช้พื้นที่มากขึ้นก็ต่อเมื่อไฟล์มีการเปลี่ยนแปลงเท่านั้น
  • ผู้ช่วยความเข้ากันได้เกมนี้ได้รับการทดสอบใน Corvus Arcade การอัปเดตอาจส่งผลต่อความเข้ากันได้
  • แท็กเพิ่มแท็ก เช่น Co-op, Relaxing, Finished หรือ Family โดยแยกแท็กด้วยเครื่องหมายจุลภาค
0.7.0
  • ติดตั้งเกมที่มีหลายส่วนให้ Point Corvus Arcade ชี้ไปยังโฟลเดอร์ที่เก็บไฟล์ติดตั้งที่มีหมายเลขไว้ แล้วโปรแกรมจะตรวจสอบไฟล์เหล่านั้น แจ้งให้ทราบหากมีไฟล์ใดขาดหายไปหรือเสียหาย จากนั้นจึงดำเนินการติดตั้ง
  • หน้าต่างโปรแกรมติดตั้งไม่เปิดขึ้นอยู่เบื้องหลังโปรแกรมเปิดใช้งานอีกต่อไปหน้าต่างของโปรแกรมติดตั้งเคยเปิดขึ้นอยู่ด้านหลังโปรแกรมเปิดใช้งาน ทำให้ดูเหมือนติดค้างขณะรอการคลิก แต่ตอนนี้มันจะขึ้นมาอยู่ด้านหน้าโดยอัตโนมัติ
  • เกมของคุณจะปรากฏขึ้นทันทีที่โปรแกรมติดตั้งเสร็จสิ้นCorvus Arcade ตอนนี้จะรอจนกว่าโปรแกรมติดตั้งจะปิดลงก่อนที่จะเริ่มค้นหา ดังนั้นมันจะค้นหาเกมได้เองโดยไม่ต้องขอให้คุณค้นหาโปรแกรมนั้น
  • การติดตั้งจะไม่ล้มเหลวอีกต่อไปเมื่อเลือกไดรฟ์ผิดโปรแกรมติดตั้งเคยเสนอตำแหน่งที่ macOS ไม่อนุญาต และจากนั้นจะหยุดลงพร้อมข้อผิดพลาดในการเข้าถึง แต่ตอนนี้โปรแกรมติดตั้งจะเริ่มทำงานในโฟลเดอร์ภายในคอนเทนเนอร์ของเกมเอง
  • การติดตั้งที่ล้มเหลวจะแสดงข้อความดังกล่าวเมื่อโปรแกรมติดตั้งหยุดทำงานก่อนเวลา Corvus Arcade จะแจ้งให้ทราบแทนที่จะทิ้งเกมว่างไว้ในไลบรารีของคุณ
  • ดูว่าโปรแกรมที่กำลังติดตั้งกำลังทำอะไรอยู่โปรแกรมเปิดตัวจะแสดงปริมาณข้อมูลที่เขียนไปแล้ว แจ้งให้ทราบเมื่อยังอยู่ในขั้นตอนการคลายการบีบอัด และแจ้งให้ทราบเมื่อไม่มีการดำเนินการใดๆ เกิดขึ้นเป็นเวลาหลายนาที
0.6.0
  • จับภาพหน้าจอขณะเล่นกดลัดขณะเล่นเกมเพื่อจับหน้าต่างเกม จากนั้นเรียกดูภาพในหน้าเกมด้วยตัวดูภาพที่มีแกลเลอรี่และปุ่มลูกศร
  • แปดธีมสีมีทั้งธีมมืดและธีมสว่างให้เลือก 4 แบบ โดยตั้งค่าได้ที่การตั้งค่า ส่วนธีมเริ่มต้นจะถูกดึงจากไอคอนแอป
  • รายการโปรดและการค้นหาปักหมุดเกมที่คุณเล่นไว้ด้านบนของคลังเกมและแถบด้านข้าง ค้นหาตามชื่อ และเรียงตามการเล่นล่าสุด ชื่อ หรือขนาด
  • การบันทึกของคุณได้รับการป้องกันการลบเกมจะถามก่อน บอกจำนวนไฟล์บันทึกที่จะหายไป และเสนอให้ส่งออกก่อนลบสิ่งใด
  • ปุ่ม Alt ส่งถึงเกมของคุณแล้วเกมบน Windows ตอนนี้สามารถรับ Alt ซึ่ง macOS เคยสงวนไว้สำหรับพิมพ์อักขระพิเศษ เกมที่ผูก Alt ไว้จะใช้งานได้ทันทีโดยไม่ต้องตั้งค่า
  • เปลี่ยนชื่อเกมแก้ไขชื่อที่ร้านค้าระบุผิด หรือชื่อที่ได้จากชื่อไฟล์ในคลังเก็บข้อมูล
  • ส่งออกคลังเกมของคุณบันทึกรายการเกม การตั้งค่า และการตั้งค่าเฉพาะเกมลงในไฟล์ขนาดเล็กไฟล์เดียว แล้วกู้คืนบน Mac เครื่องอื่นได้
  • เกม DirectX 9 จะถูกทำเครื่องหมายCorvus Arcade จะอ่านว่าเกมแสดงผลด้วยอะไร และเตือนเมื่อไม่มีแบ็กเอนด์กราฟิกใดรันได้ ก่อนที่คุณจะเสียเวลาดาวน์โหลด
0.5.0
  • เพิ่มเกมโดยตรงจากไฟล์ zip หรือ rarตอนนี้เกมที่มีอยู่ในรูปแบบไฟล์อัดแน่นโดยไม่มีตัวติดตั้ง จะถูกแยกไฟล์ออกมาได้เอง Corvus Arcade จะค้นหาโปรแกรมภายในและติดตั้งให้ทันที
  • ตรวจสอบการรองรับระบบป้องกันการโกงก่อนการติดตั้งตอนนี้เกมแต่ละเกมจะแสดงว่าระบบป้องกันโกงทำงานบน Mac หรือไม่ ทำให้คุณรู้ก่อนดาวน์โหลดแทนที่จะรู้หลังจากดาวน์โหลดแล้ว
  • ภาพปกและคำอธิบายในภาษาของคุณตอนนี้ภาพปกจะดึงมาจาก ร้านค้า โดยตรง ทำให้ข้อมูลทันสมัยเสมอ และคำอธิบายของเกมแต่ละเกมจะแสดงในภาษาที่คุณใช้ Corvus Arcade

FAQ

คำถามที่พบบ่อย

Overwatch ทำงานบน Mac ได้หรือไม่

ใช่ สำหรับ Apple Silicon Corvus Arcade ติดตั้ง Battle.net และ Overwatch ลงในคอนเทนเนอร์ Windows แบบแยกส่วนแล้วรันผ่าน Wine 11 ที่รวมอยู่ในแอป โดยใช้ D3DMetal ของ Apple ดังนั้นจึงไม่ต้องใช้ใบอนุญาต Windows, Boot Camp หรือเครื่องเสมือน

สามารถเล่นเกม Windows บน Apple Silicon โดยไม่ต้องใช้ CrossOver ได้หรือไม่

ใช่ Wine 11, DXMT และ D3DMetal engine บรรจุอยู่ในแอปแล้ว จึงไม่ต้องสมัคร CrossOver ไม่ต้องใช้ Homebrew หรือคำสั่ง Terminal ดาวน์โหลดแอปแล้วกด Launch

Corvus Arcade ใช้งานได้ฟรีหรือไม่

ใช่ ฟรี ไม่มีบัญชี ไม่มีการรวบรวมข้อมูลและไม่มีการติดตาม ทำงานบน Mac ของคุณทั้งหมด

สามารถเพิ่มเกมใดได้บ้าง

เกม Windows ที่มีการติดตั้งหรือไฟล์ .exe แต่ละเกมอยู่ในคอนเทนเนอร์แยกกัน Overwatch เป็นชื่อที่คัดสรรแล้วและได้รับการพิสูจน์แล้ว และติดตั้งจาก GOG ที่ไม่มี DRM ผ่านการทดสอบแล้ว เกมที่มีระบบป้องกันผู้โกงหรือเกมที่รองรับ DirectX 12 เท่านั้นมักจะไม่ทำงาน

ฉันต้องการ Rosetta 2 หรือไม่?

ใช่ และ Corvus Arcade จะติดตั้งให้หากคุณไม่มี ระบบตรวจสอบครั้งแรกยังยืนยันว่ามีการติดตั้งเครื่องยนต์ที่รวมมาและตรวจสอบว่ามีพื้นที่ว่างบนดิสก์เพียงพอ

Corvus Arcade ปลอดภัยหรือไม่?

ใช่ ทุกเวอร์ชันได้รับการลงลายมือชื่อด้วยใบรับรอง Apple Developer ID และผ่านการรับรองจาก Apple ซึ่งสแกนหามัลแวร์ก่อนเผยแพร่ macOS จะตรวจสอบลายมือชื่อเมื่อคุณเปิดแอป ดังนั้นคุณจะไม่เห็นคำเตือนนักพัฒนาที่ไม่รู้จัก และดิสก์ภาพยังได้รับการประทับตราด้วยเช่นกัน ทำให้การตรวจสอบใช้งานได้แม้ไม่มีอินเทอร์เน็ต Corvus Arcade ไม่เก็บข้อมูลและไม่ต้องการบัญชี

คุณต้องการ Mac เครื่องไหน?

An Apple Silicon Mac, meaning M1 or newer, running macOS 26 or later. Intel Macs are not supported. Battle.net plus Overwatch needs roughly 60 GB of free space.
