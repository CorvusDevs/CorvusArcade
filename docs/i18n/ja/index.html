Corvus Arcade

Windows ゲームを Apple シリコン Mac で実行できます。Wine 11 に DXMT と Apple の D3DMetal を組み込んだネイティブランチャーで、CrossOver やターミナルは不要です。ゲームを選択して Play を押すだけです。

無料ダウンロード Free · macOS 26+ · Apple Silicon only Apple Developer ID で署名され、Apple によって検証済みです。

現在動作するゲーム

Battle.net、Overwatch、DRM 非搭載の GOG インストーラー、および単なるアーカイブ形式で配信されるゲームはすべてテスト済みで動作確認済みです。アンチチートで保護されたゲームは起動できません。DirectX 12 専用タイトルは未確認です。Corvus Arcade はインストール前に、どのゲームが動作するかを通知します。

実際の動作

ランチャー、ツールキットではありません

機能

ランチャー、ツールキットではありません

ワンクリックでオーバーウォッチ

厳選されたセットアップはクリーンなコンテナを作成し、Battle.net をインストールして試合に直結します。設定不要です。

あなたのエンジン、バンドル済み

Wine 11 に DXMT と Apple の D3DMetal がアプリ内に搭載されており、CrossOver サブスクリプション、Homebrew、Terminal は不要です。

ライブラリの概要

ホームビューには、すべてのゲームとその現在のステータス（準備完了、再生中、またはセットアップが必要）が表示されます。

プレイ中のスクリーンショット

ショートカットはゲームウィンドウのみをキャプチャし、画面全体ではなくゲームページ上のビューアで表示されます。ギャラリーと矢印キーで操作できます。

ゲーム毎のグラフィックス

各ゲームごとに DXMT または D3DMetal、GPTK 3 または GPTK 4、ウィンドウモード、およびフレームレート上限を選択できます。

GPU 使用状況とメモリ使用状況

ゲームプレイ中に GPU とメモリがどのくらい稼働しているかを、ゲージとローリンググラフで表示します。

セーブデータは保護されます

ゲームの削除はまず確認を求めます。失われるセーブファイルの数をカウントし、削除前にエクスポートするかどうかを提案します。

準備チェック

ゲームページでは、メモリ不足などの問題を検知し、プレイ前にワンタップで修正できます。

フレームキャップと FPS オーバーレイ

フレームレートを制限して発熱とファンノイズを軽減し、MetalFX アップスケーリングを有効化するとともに、必要に応じてリアルタイムの FPS 表示をオンにできます。

FAQ

よくある質問

Overwatch は Mac で動作しますか？

はい、Apple Silicon に対応しています。Corvus Arcade は Battle.net と Overwatch を孤立した Windows コンテナにインストールし、Apple の D3DMetal を使用したバンドルされた Wine 11 エンジンで実行するため、Windows ライセンス、Boot Camp、または仮想マシンは不要です。

Apple Silicon で CrossOver がない状態で Windows ゲームを実行できますか？

はい。Wine 11、DXMT、D3DMetal エンジンがアプリに内蔵されているため、CrossOver サブスクリプション、Homebrew、Terminal コマンドは不要です。アプリをダウンロードして「起動」を押してください。

Corvus Arcade は無料ですか？

はい、無料でアカウント、テレメトリ、トラッキングは一切不要です。完全に Mac 上で動作します。

どのゲームを追加できますか？

Windows ゲームのインストーラーまたは .exe ファイル（それぞれ独立したコンテナに格納）がサポートされています。Overwatch は厳選され実績のあるタイトルであり、DRM 非搭載の GOG インストーラーもテスト済みです。アンチチート機能搭載のゲームや DirectX 12 専用タイトルは動作しない場合があります。

Rosetta 2 は必要ですか？

はい、Corvus Arcade は不足している場合は自動的にインストールします。最初のシステムチェックでは、バンドルされたエンジンと十分な空きディスク容量があることも確認されます。

Corvus Arcade のインストールは安全ですか？

はい。すべてのリリースは Apple Developer ID 証明書で署名され、Apple がマルウェアをスキャンしてから公開しています。macOS はアプリを開いた際にその署名を確認するため、「不明な開発者」という警告は表示されません。ディスクイメージもスタップ済みなので、オフラインでもチェックが機能します。Corvus Arcade はデータを収集せず、アカウントも不要です。

どの Mac が必要ですか？

An Apple Silicon Mac, meaning M1 or newer, running macOS 26 or later. Intel Macs are not supported. Battle.net plus Overwatch needs roughly 60 GB of free space.
