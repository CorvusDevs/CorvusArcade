# Security policy

## Supported version

Security fixes are provided for the latest published Corvus Arcade release.

## Report a vulnerability privately

Please use [GitHub private vulnerability reporting](https://github.com/CorvusDevs/CorvusArcade/security/advisories/new). Include the affected version, reproduction steps, impact, and any proof of concept that is safe to share.

Do not open a public issue for an unpatched vulnerability. Do not include credentials, personal data, or third-party game account information in a report.

You will receive acknowledgement through GitHub. Public disclosure should wait until a fix is available or a disclosure date has been agreed.
