# Corvus Arcade support

## Before reporting a problem

1. Install the latest Corvus Arcade release.
2. Open the affected game's Compatibility Assistant and apply its recommended fixes.
3. Confirm that macOS, the game launcher, and the game are fully updated.
4. Retry once with the recommended graphics backend.

## Choose the right report

- Use the [bug report form](https://github.com/CorvusDevs/CorvusArcade/issues/new?template=bug-report.yml) when Corvus Arcade itself crashes, displays incorrect information, or a launcher feature does not work.
- Use the [game compatibility form](https://github.com/CorvusDevs/CorvusArcade/issues/new?template=game-compatibility.yml) when a Windows game or installer fails, stalls, or renders incorrectly.

Search [existing issues](https://github.com/CorvusDevs/CorvusArcade/issues) first. Add information to a matching issue instead of opening a duplicate.

## Useful diagnostics

Include the following when the report form asks for it:

- Corvus Arcade version
- Mac model and memory
- macOS version
- Game and launcher version
- Selected backend and GPTK generation
- The exact last visible step or error
- Whether the same operation worked before

Remove account names, paths containing your user name, license keys, and other personal information before attaching logs or screenshots.

## Security issues

Do not report vulnerabilities in a public issue. Follow the private process in [SECURITY.md](SECURITY.md).
